# Balon Patlatma Oyunu

Bu klasör, repodaki diğer yapılardan bağımsız çalışan basit bir web oyunudur.

## Çalıştırma

1. `index.html` dosyasını bir tarayıcıda açın.
2. **Yeniden Başlat** butonuna basarak oyunu başlatın.
3. Balonlara tıklayarak puan toplayın.

## Oyun Kuralları

- Süre: 30 saniye
- Can: 5
- Kaçan her balon 1 can götürür.
- Balonun hızına göre kazanılan puan değişir.
